# AI 驱动的企业应用实施与交付｜个人作品集

**四个月跨领域企业项目实践（2026-07-13 起）** · 独立负责分配给自己的项目 · Codex 等 AI 工具辅助主要软件实现 · 真实业务数据与现场结果验证

## 我能够独立承担什么

公司没有正式软件部门，软件项目由两名员工分别负责不同方向。我**独立推进自己负责的项目**，从业务需求和数据来源核实、实施方案组织、AI 协作开发，到现场部署、真实结果测试、问题修复和后续维护。

- **了解企业系统如何取得数据：**视平台授权与开放程度，采用官方 API、浏览器自动化、人工认证后导出与文件导入等方式；接触过 ERP、OA、企业微信、OCR、监控/NVR，以及传感器和 PLC 相关环境。
- **快速将业务目标变成可用工具：**简单业务程序可在较短时间完成原型和现场验证；岗位异常检测的核心效果在约一天内调试出来并投入实际使用。
- **以真实结果验收：**通过源报表、页面、导出记录、运行日志、实际操作和设备状态判断软件是否满足要求；有问题就反馈 AI 修改、复测。
- **明确实施范围：**可以交付的应用转入使用与维护，不为了展示复杂技术而无限增加功能；有问题的功能如实标注。

**工作分工说明：** AI 负责主要代码生成、修改和技术方案建议；本人承担业务事实核实、需求约束、实施组织与结果验证。独立负责项目，不等于声称所有源码由本人手写。

## 项目管理方式

**业务目标 → 核实平台与数据 → AI 协作实现 → 现场黑盒测试 → 反馈修复 → 阶段交付 / 维护。**

我承担的软件项目与另一位同事负责的车辆管理、车辆违章采集等项目分别实施，不把同事项目算作自己的成果。
