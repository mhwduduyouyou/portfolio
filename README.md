## 我解决过的工程问题

- **AI 推理部署：** GPU 引擎池、同卡并发竞争、资源不足时的降级和恢复。
- **数据正确性：** 浏览器自动化采集、跨来源去重、staging 校验、失败不覆盖旧数据。
- **跨系统可靠性：** 幂等约束、Outbox、状态机、超时结果未知时的 Reconciliation。
- **真实验证边界：** 区分生产运行、受控试写、离线测试与演示数据。

## 开发与交付方式

面对真实业务需求，我负责定义目标与验收条件，和 Codex 共同推演实现方案与异常路径，推动代码实现及现场部署，并在用户反馈后持续修复缺陷、优化效果。**首次上线不等于所有功能完成，也不等于后续没有维护工作。**
