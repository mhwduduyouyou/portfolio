## 代表性工程与交付问题

- **数据正确性：**源与业务线匹配、去重、暂存校验、失败保留旧数据，区分调度成功／按配置跳过／失败。
- **外部副作用安全：**外部建单前的检查条件、幂等、Outbox、状态约束、超时结果未知时的 Reconciliation，避免盲目重发。
- **AI 应用质量：**保留识别评测口径、低置信提示与人工纠错，区分模型能运行和业务效果可验收。
- **现场资源约束：**以帧新鲜度和序号判断实际视频处理，触及 CPU/GPU 阈值时停止扩容并回退。

## 我的工作方式

**需求澄清 → 业务规则与异常路径 → AI 协作实现 → 环境部署 → 运行核验 → 反馈迭代与回滚。**

没有其他人类开发人员参与的项目中，我负责需求定义、方案组织与取舍、进度推进、技术结果核查及交付沟通；代码通过 AI 工具辅助开发。案例分别注明「生产运行」「受控实写」「候选试运行」与「未验收」。
